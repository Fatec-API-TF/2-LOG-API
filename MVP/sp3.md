<h2> 🎯 Objetivo do MVP:  </h2>
  <h3> Requisitos Funcionais:</h3>
    - Dashboard: Visualização de indicadores por estado e evolução histórica entre 2015 e 2025. </br> 
    - Filtros: Segmentação dos dados por região, ano, tipo de veículo e gravidade dos sinistros. </br> 
    - Integração de dados: Cruzamento de informações do DATASUS e PRF. </br> 
    - Entrega final: Documentação técnica, relatório de análise e vídeo de apresentação da solução. </br>

## 🔑 User Stories (Backlog do MVP)

| ID | User Story | Prioridade | Estimativa (Story Points) |
| :--- | :--- | :--- | :--- |
| US1 | Como pesquisador do ONSV, quero navegar por um mapa do Brasil com dados agregados por estado, para visualizar geograficamente os indicadores de segurança viária. | Alta 🔴 | 5 pontos |
| US2 | Como analista de BI, quero visualizar gráficos de tendência dos indicadores entre 2015 e 2025 por estado, para entender a evolução histórica da segurança viária. | Alta 🔴 | 5 pontos |
| US3 | Como consultor, quero acessar informações relevantes em poucos cliques, para ter uma navegação intuitiva pela plataforma. | Média 🟡 | 3 pontos |
| US4 | Como consultor, quero acessar a plataforma de forma responsiva em diferentes dispositivos, para consultar os dados também fora do desktop. | Média 🟡 | 3 pontos |
| US5 | Como analista de dados, quero aplicar filtros por tipo de veículo, região, ano e gravidade do sinistro, para segmentar a análise conforme meu interesse. | Alta 🔴 | 5 pontos |
| US6 | Como pesquisador, quero aplicar filtros cruzados entre dados de saúde (DATASUS) e transporte (PRF), para relacionar mortalidade e sinistros de forma integrada. | Alta 🔴 | 5 pontos |
| US7 | Como equipe de projeto, quero produzir a documentação técnica completa do projeto, incluindo scripts de limpeza e modelagem em Python, para permitir a reprodutibilidade da solução. | Alta 🔴 | 5 pontos |
| US8 | Como cliente final, quero receber um relatório técnico de análise com boas práticas e desafios por estado, para apoiar a formulação de políticas públicas ou estudos acadêmicos. | Alta 🔴 | 5 pontos |
| US9 | Como cliente final, quero um vídeo no YouTube apresentando a solução final, para cumprir a forma de entrega definida para a Entrega 3 (26/nov). | Alta 🔴 | 3 pontos |
